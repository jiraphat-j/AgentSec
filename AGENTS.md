# AgentSec Lab — Agent Guide

Short entry point and configuration index for AI agents and engineering skills operating in this repository.

---

## Agent Skills Configuration

### Issue Tracker
GitHub Issues tracked via `gh` CLI. See [docs/agents/issue-tracker.md](docs/agents/issue-tracker.md).

### Triage Labels & Lifecycle
Canonical 5-role labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`) and state transitions. See [docs/agents/triage-labels.md](docs/agents/triage-labels.md).

### Domain Docs
Single-context repository layout (`CONTEXT.md` and `docs/adr/` at repo root). See [docs/agents/domain.md](docs/agents/domain.md).

### Security Baseline ⭐
Non-negotiable security boundaries: zero secrets, host/socket isolation, and mandatory human review for auth, crypto, and execution surfaces. See [docs/agents/security.md](docs/agents/security.md).

### Definition of Done
Quality and handoff checklist: passing tests, clean lint/types, strict scope adherence, and human review preparation. See [docs/agents/definition-of-done.md](docs/agents/definition-of-done.md).

### Wayfinder
Frontier problem solving with Map and Child tickets. See [docs/agents/wayfinder.md](docs/agents/wayfinder.md).
